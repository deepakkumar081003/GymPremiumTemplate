Image replacement guide for white-label gyms:

1) Keep the same filenames for easiest replacement:
   - sample-gym-main.svg
   - sample-gym-secondary.svg
   - thuli-logo-placeholder.svg

2) Replace with JPG/PNG/SVG if needed, but keep dimensions premium quality:
   - main visuals: 1600x1000 or larger
   - secondary visuals: 1400x900 or larger
   - logo banner: 800x280

3) If you change filenames, update references in:
   - src/app/page.tsx
   - src/app/about/page.tsx
   - src/app/plans/page.tsx
   - src/app/gallery/page.tsx
   - src/app/contact/page.tsx
